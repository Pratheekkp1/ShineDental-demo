# Shine Dental: Kids & Family Site Redesign

A redesign concept for **Shine Dental** with a friendlier, kid-focused look, built as a proposal alongside the [original site](https://github.com/Pratheekkp1/Shine-Dental).

**Live demo:** https://web2-five-chi.vercel.app

## Features

- Hero, about, services, "Meet Dr. Lee", patient reviews and scheduling sections
- Hamburger navigation on mobile; every "Book" call to action smooth-scrolls to the scheduling form
- Scroll-triggered reveal animations

## Tech

HTML5 · CSS3 · vanilla JavaScript · Vercel
